# Chronological Brain Age Estimation Task

This directory contains code for the **chronological brain age estimation task** evaluated in the B-RAPIDD study.

The aim of this analysis is to assess whether accelerated MRI preserves age-related structural information captured by the AI model.

## Input

The brain age pipeline uses preprocessed MRI volumes generated by the preprocessing workflow described in:

`../preprocessing/`

Routine and accelerated MRI acquisitions are processed independently and used as input to the regression model.

## Model

Brain age estimation is performed using the pretrained UxLSTM/BrainNext encoder with a scalar regression head.

The regression head predicts a single continuous value corresponding to estimated chronological brain age.

Contains utility functions for regression training and evaluation.

### `example.py`

Provides an example of how to configure and run the downstream brain age regression model.

## Evaluation

Brain age performance is assessed by comparing predicted brain age with chronological age.

The analysis includes:

- Mean Absolute Error (MAE)
- Pearson correlation
- Brain age gap

Predictions obtained from routine and accelerated MRI are additionally compared to assess agreement across acquisition protocols.

## Related Study

This analysis forms part of the B-RAPIDD study:

**Accelerated MRI Preserves AI-Derived Neuroimaging Biomarkers for Dementia Diagnosis and Monitoring.**

For the complete study workflow, preprocessing information, data availability, and citation details, see the main repository README.
