# Diagnostic Classification Task

This directory contains code for the **diagnostic classification task** evaluated in the B-RAPIDD study.

The aim of this analysis is to assess whether accelerated MRI preserves disease-relevant information required for AI-based diagnostic classification.

## Classification Tasks

Two binary classification tasks were evaluated:

- **Disease vs non-neurodegenerative control**
- **Alzheimer’s disease vs non-neurodegenerative control**

Classification was performed using AI-derived features from routine and accelerated MRI acquisitions.

Diagnostic robustness was additionally assessed using an independent AI model.

## Input

The classification pipeline uses preprocessed MRI volumes generated by the preprocessing workflow described in:

`../preprocessing/`

### `uxlstm_downstream.py`

Defines the downstream classification model built on the UxLSTM/BrainNext encoder with a task-specific classification head.

### `training_utils.py`

Contains utility functions used for downstream model training and evaluation.

### `example.py`

Provides an example of how to configure and run the downstream classification pipeline.

## Evaluation

Classification performance in the study was assessed using:

- Accuracy
- Precision
- Recall
- F1 score
- Area under the receiver operating characteristic curve (AUROC)

Agreement between predictions obtained from routine and accelerated MRI was additionally assessed using Cohen’s kappa.

## Related Study

This analysis forms part of the B-RAPIDD study:

**Accelerated MRI Preserves AI-Derived Neuroimaging Biomarkers for Dementia Diagnosis and Monitoring.**

For the complete study workflow, preprocessing information, data availability, and citation details, see the main repository README.
